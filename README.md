# Implement Client Scripts and UI Policy (Incident)

## Objective
To implement and test Client Scripts and UI Policy in the ServiceNow Incident application.

## Client Scripts Implemented

### 1. onChange Client Script
Executes when the value of a field changes.

### 2. onSubmit Client Script
Executes when an Incident form is submitted.

### 3. onCellEdit Client Script
Executes when a field value is edited directly from a list.

## UI Policy

A UI Policy is implemented on the Incident form to dynamically control field behavior based on conditions.

### UI Policy Action
The UI Policy Action is used to control the field properties such as:
- Mandatory
- Visible
- Read-only

## Testing and Validation
The Client Scripts and UI Policy were tested successfully in the Incident application.
